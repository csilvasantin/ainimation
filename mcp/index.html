Dónde vive el dato de lo que se crea aquí

Este sitio autora; el dato acaba en sus hermanos, y ahí sí hay contrato:

  • Trabajo y puntos → yokup.com/mcp (https://api.yokup.com). Todo lo que se hace aquí se declara y puntúa en Yokup.
  • Biblioteca → pixeria.com/mcp. El contenido creado se guarda ahí, etiquetado.
  • Emisión → admira.tv/mcp, con su proof-of-play y sus tres herramientas MCP vivas.

Trampas

  • El sitio se publica al empujar a main: no hay deploy.sh. Un push es una publicación.
  • El ?v= de los assets lo sella un workflow de GitHub al hacer push; no lo pongas a mano.
  • director-interactivo es un proyecto distinto en el censo de Yokup, pero vive en /studio.html de este mismo dominio: hereda estas dos puertas.
