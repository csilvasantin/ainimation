# Afinar un interactivo en Director / Refine an interactive in Director

ES: Abre el proyecto en el Creador y pulsa **Afinar en Director**. Cada pantalla se convierte en una marca S1, S2… del Score. Selecciona un sprite en el Stage o Score y utiliza el inspector para cambiar texto, posición, tamaño y colores. Las imágenes aparecen en el Cast; las zonas táctiles conservan su geometría sobre la imagen completa. En Behaviour/XPL puedes cambiar el destino de un botón mediante **saltar a la marca**, seguido de **detener**. **Probar recorrido** ejecuta el mismo reproductor que la exportación y el envío.

**Guardar interactivo** actualiza sólo el proyecto vinculado y comprueba su revisión para evitar sobrescribir otra pestaña. **Volver al Creador** guarda y recupera la película y las marcas que había antes de abrir el interactivo. Se conserva además una copia de recuperación local. Sincroniza el proyecto desde el Creador y prepara un envío nuevo para publicarlo en una pantalla: las entregas anteriores permanecen fijas.

La conexión admite tarjetas, zonas táctiles y cafeterías nativas. Para estas últimas, pulsa **Catálogo y cesta** en la barra del interactivo o **Carta → Editar catálogo y cesta**. Edita nombres y descripciones de categorías; nombre, descripción, familia, categoría, precio en euros, opciones y disponibilidad de productos. En Cesta puedes cambiar título, mensaje vacío, texto de continuar, máximo de unidades por línea (1–20) y agrupación de opciones iguales. El reinicio por inactividad admite 10–300 segundos. **Aplicar cambios** conserva el borrador en Director; **Cancelar** descarta ese borrador. **Guardar interactivo** o **Volver al Creador** lo guarda en el mismo registro. El Stage muestra la cafetería nativa; **Probar recorrido** permite recorrer catálogo, opciones, cantidades y cesta. Los pagos siguen siendo simulados. El Creador ofrece los mismos ajustes. Las referencias, IDs y metadatos se conservan; no se convierten a la carta genérica de Starbucks. Añadir o quitar productos/categorías no forma parte de este editor de ajustes. Para añadir o quitar pantallas y botones, vuelve primero al Creador. Los tiempos, animaciones, scripts adicionales, giros y recortes deben guardarse como película Director; el guardado de vuelta los rechaza con un aviso, conserva el trabajo en Director y no modifica el interactivo. La imagen se mantiene completa y fija; puede sustituirse por otra imagen compatible. Los textos del proyecto usan el campo ES del inspector; un cambio sólo en EN también se recoge como texto principal. El retorno actual no crea una traducción bilingüe del interactivo.

EN: Open a project in Creator and choose **Refine in Director**. Each screen becomes an S1, S2… Score marker. Select a sprite in Stage or Score and use the inspector to change text, position, size and colors. Images appear in Cast; hotspots keep their geometry over the full image. In Behaviour/XPL, change button targets using **jump to the mark**, followed by **stop**. **Test journey** uses the same player as export and delivery.

**Save interactive** updates only the linked project and checks its revision against concurrent tabs. **Return to Creator** saves and restores the previous movie and markers; an additional local recovery copy is retained. Sync in Creator and prepare a new delivery for a screen. Existing snapshots remain immutable.

The bridge supports cards, hotspots and native cafeterias. For a cafeteria, choose **Catalog and basket** in the interactive bar or **Menu → Edit catalog and basket**. Edit category names/descriptions and product names, descriptions, family, category, euro prices, options and availability. Basket settings include title, empty message, checkout label, maximum units per line (1–20), and merging identical choices. Idle reset accepts 10–300 seconds. **Apply changes** updates the Director draft; **Cancel** discards that draft. **Save interactive** or **Return to Creator** saves the same record. Stage displays the native cafeteria; **Test journey** covers catalog, options, quantities and basket. Payment remains simulated. Creator provides the same settings. References, IDs and metadata remain intact; this is separate from the generic Starbucks menu. Adding/removing products or categories is outside this settings editor. Add/remove screens and buttons in Creator first. Timing, animations, additional scripts, rotation and cropping must be saved as Director movies; returning these changes displays an error, keeps the Director work and leaves the interactive unchanged. Images remain full and static and may be replaced by compatible images. ES text edits take precedence; an EN-only change is also used as primary text. This does not create a bilingual interactive.

Contract: `interactiveSource` retains the project ID, source revision, full validated source project and sprite bindings in the Director movie. Source library records use optimistic revision checks. The previous working movie and marker JSON are saved under a unique `ainimation:director:recovery:<uuid>` key before import; restoration uses the same key. No cloud credential or fleet command is added to Director.

Cafeteria contract: `interactiveSource.kind="cafeteria"` retains the complete source. `plan.cafeteria` and `plan.resetSeconds` are validated on return. A single native kiosk sprite (`view="cafeteria"`) uses the exact export player. The optional `cafeteria.basket` settings are backwards compatible; absent settings preserve the existing bag flow and limits. Basket contents are customer session state, never saved as catalog configuration.

## Sesión al volver de Director / Session on return from Director

ES: Al abrir Director desde el Creador, la sesión verificada se mantiene abierta. Volver al Creador recupera el proyecto guardado y permite sincronizar y enviar sin otro acceso mientras la credencial siga vigente. Recargar o cerrar el Creador sí exige iniciar sesión. La credencial no se guarda ni se pasa a Director.

EN: Opening Director from Creator keeps the verified session open. Return to Creator reloads the saved project and allows sync and delivery without another sign-in while the credential remains valid. Reloading or closing Creator still requires sign-in. The credential is neither stored nor passed to Director.

Contrato / Contract: el Creador mantiene su documento y su credencial en memoria. Director se abre dentro de la página y devuelve sólo ID y revisión por un canal por apertura; se comprueban origen, ventana e identidad del proyecto. La revisión se valida contra la biblioteca antes de actualizar el editor. Los avisos de cambios de otras pestañas siguen activos. / Creator retains its document and memory-only credential. Director opens within the page and returns only project ID and revision through a per-opening channel, checked against origin, window and project. Library revision is checked before refreshing the editor. Other-tab conflict warnings remain active.
