## Descargar informe CSV / Download CSV report · 22 October 2026

EN: In **Delivery history**, expand a batch and choose **Download CSV**. The report contains only that batch: UTC date, project, version, Xpace and ID, screen and ID, result and destination link. It needs no Google sign-in and never resends or assigns the interactive. Pending/interrupted targets are reported as “Unconfirmed”, without fabricated links. The filename identifies date, revision and batch. History and projects are retained.

CSV contract: UTF-8 with BOM, comma-delimited, quoted fields, doubled internal quotes and CRLF records. Headings/statuses follow the interface language. Formula-like text is prefixed with an apostrophe, including leading whitespace/control characters; source metadata is unchanged. Only validated history fields are serialized; no credentials, project contents, owner identity or raw error messages. The BOM follows [Microsoft’s UTF-8 CSV guidance](https://support.microsoft.com/es-es/excel/opening-csv-utf-8-files-correctly-in-excel). Spreadsheet importers can select comma as the delimiter if their regional default differs. The browser prepares the file locally; it calls no API and requires no clipboard access.
