# Editar con Ainimation dentro de Stock / Edit with Ainimation inside Stock

ES: En el detalle de una cápsula con guion de origen, **Editar con Ainimation** aparece inmediatamente a la izquierda de **AI Abrir en AINimation**. El botón activa el mismo motor de edición directamente en el detalle actual: no cambia la URL, no abre otra pestaña y no utiliza un iframe. Pulsa el titular o la frase para editar sobre la composición; los campos, la vista en directo y la comparación comparten el mismo borrador. El vídeo anterior se pausa. «Volver al vídeo» o Escape cierra sólo la edición; la × del detalle cierra el detalle completo. Al salir o cambiar de pieza se guarda localmente el borrador si hay cambios y se detienen los medios. Nunca se guarda la clave del Stock en ese borrador.

EN: In a capsule detail with a saved source script, **Edit with Ainimation** appears immediately before **AI Open in AINimation**. It mounts the same editing engine in the current detail: the URL stays unchanged, no new tab opens and no iframe is used. Click the headline or sentence to edit on the composition; fields, live preview and comparison share the same draft. The previous video pauses. “Return to video” or Escape closes editing only; the detail’s × closes the whole detail. Leaving or changing the item stores any changed draft locally and stops media. The Stock key is never saved with the draft.

ES: «Generar» conserva la revisión y la autorización ya existentes. Cuando terminan ambas orientaciones, «Ver versión publicada» abre el nuevo resultado dentro del mismo Stock, conservando los parámetros actuales. Los borradores locales pertenecen al origen actual (Admira Studio, Pixeria o Ainimation); sólo las versiones generadas se comparten mediante el servicio de cápsulas. Los medios sin referencia `capsula-url:<hash>` mantienen sus controles anteriores. Una referencia válida sin pista limpia conserva la edición por campos y la comparación, con el aviso correspondiente.

EN: “Render” retains the existing revision and authorization checks. When both orientations finish, “View published version” opens the result in the same Stock origin with the current query parameters preserved. Local drafts belong to their current origin (Admira Studio, Pixeria or Ainimation); rendered versions are shared through the capsule service. Media without a `capsula-url:<hash>` reference retain their prior controls. Valid references without clean media retain form editing and comparison with an explicit notice.

## Shared editor contract

ES: El aviso de conflicto compara **Mi copia** con **Otra pestaña**, campo por campo, antes de elegir. Incluye textos, tema, cifra, unidad y cartelas; se actualiza al editar o recibir cambios de la otra pestaña. No modifica ninguna copia por mostrarla. Las copias iguales lo indican aunque sus historiales difieran. Si la otra copia pertenece a otra revisión o no se puede leer, se explica y se desactiva recuperarla; la copia propia sigue conservada. Los textos se muestran como texto literal.

EN: The conflict notice compares **My copy** with **Other tab**, field by field, before choosing. It includes text, topic, figure, unit and cards, updating after local or other-tab edits. Viewing changes modifies neither copy. Identical copies are identified even when histories differ. An unreadable copy or another source revision is explained and cannot be adopted; your own copy remains retained. Content is displayed as literal text.

ES: Si el borrador cambia en otra pestaña del mismo origen, se pausa la escritura compartida y la generación hasta elegir **Continuar con la otra copia** o **Conservar mi copia**. La edición local y su historial se guardan aparte en la sesión de esa pestaña, sin clave; se recuperan al volver al vídeo o recargar esa misma pestaña. Esa copia de recuperación dura lo que dure la sesión de la pestaña. No se mezclan textos automáticamente. La comprobación antes de guardar también detecta cambios cuando el evento del navegador todavía no ha llegado.

EN: When another tab changes the draft on the same origin, shared writes and rendering pause until you choose **Continue with the other copy** or **Keep my copy**. Local edits and history are backed up separately in that tab's session without passwords; returning to video or reloading that tab recovers them. Recovery lasts for that tab session. Copy is never merged automatically. A pre-save check also detects changes before the browser event arrives.

ES: El borrador y su historial se guardan automáticamente después de cada cambio, Deshacer y Rehacer. Se recuperan tras recargar la página, siempre que siga siendo la misma revisión. El aviso de guardado pertenece al navegador actual y no publica la cápsula. Si el almacenamiento falla, se muestra un aviso y se mantiene la edición en memoria; «Guardar borrador» permite reintentarlo. La clave nunca forma parte del guardado.

EN: Draft and history are saved automatically after every edit, Undo and Redo, and recovered after page reload for the same source revision. The saved notice applies to this browser and does not publish the capsule. If storage fails, a warning appears and edits remain in memory; Save draft retries. Passwords are never stored.

ES: **Deshacer** usa ⌘/Ctrl+Z. **Rehacer** usa ⌘/Ctrl+Mayús+Z (también Ctrl+Y). Funcionan en los campos y sobre la composición; no interceptan la clave del Stock ni la composición de caracteres. El historial incluye textos, tema, cifra y cartelas, además de «Recuperar original». Conserva hasta 100 estados de edición en el navegador y se recupera con el borrador al volver al vídeo. Un cambio nuevo descarta la rama de Rehacer. El historial pertenece a la revisión de origen; nunca contiene la clave ni se envía al renderizador.

EN: **Undo** uses ⌘/Ctrl+Z. **Redo** uses ⌘/Ctrl+Shift+Z (also Ctrl+Y). They work in fields and on the composition, excluding the Stock password and character composition. History covers text, topic, figure, cards and Restore original. Up to 100 editing states are retained locally and recovered with the draft after returning to video. A new edit discards the redo branch. History belongs to the source revision; it never contains the password or reaches the renderer.

The Stock adapter imports `https://www.ainimation.studio/assets/capsule-editor.mjs?v=capsule-inline-1` using CORS and checks `CAPSULE_EDITOR_EMBED_VERSION === 1`. A failed module load restores the original viewer and can be retried. It does not copy the engine, transfer credentials between origins, or create a new publication API.

`mountCapsuleEditor({host, params, signal, returnUrl, onClose})` mounts inline when `host` is provided; otherwise it retains the Director modal. `params` carries the validated capsule reference, selected asset ID/URL and orientation. It returns `{element, destroy, pause, saveDraft}`. Destruction saves only changed local copy, clears in-memory password fields, stops polling/media and disconnects the preview observer. `signal` prevents an abandoned load from mounting on a later detail. Ordinary library imports do not bootstrap a modal. Director uses `capsule-editor-entry.mjs`; cached legacy direct-script entries remain supported.

Validation: run `node --test test/stock-capsule-inline.test.mjs test/capsule-editor-link.test.mjs`. Browser integration: `PLAYWRIGHT_PATH=/path/to/playwright AINIMATION_ENGINE_ROOT=/path/to/ainimation node scripts/test-stock-capsule-inline.mjs`. The script uses two labelled Stock fixtures and blocks all content writes. Optional live mode uses an existing, ephemeral agent sign-in credential through `STOCK_INLINE_TOKEN`, never a token in a URL or repository file. Production verification uses `STOCK_INLINE_LIVE=1 STOCK_INLINE_LOCAL_ENGINE=0` and records whether real authentication was used.
